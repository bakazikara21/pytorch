畳み込みニューラルネットワークの基本的な構造

# 入力はカラー画像　縦 * 横 * 3(R,G,B)
# 順伝播の流れは
# 入力 -> 畳み込み層 -> ReLU -> 畳み込み層 -> ReLU -> 最大プーリング 
# -> 1次元ベクトル化 -> 全結合層 -> ReLU -> 全結合層 -> softmax+交差エントロピー関数 -> 損失

# パラメータは "畳み込み層の3*3のカーネル" と "全結合層の重みとバイアス" となっている。
# 最大プーリングは 2*2の領域の最大値をとってデータを縮小する
# (領域が重ならないように2*2の領域の最大値をとっていくので縦横のサイズが1/2になる)
